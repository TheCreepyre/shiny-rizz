# ✨ Shiny Rizz

A beautiful, interactive light shining website with glowing effects and animations.

## Features

- ✨ Mesmerizing glowing light orb with smooth pulsing animations
- 🌟 Twinkling stars in the background
- 🎨 Interactive color changing effects
- 💫 Hover and click interactions
- 📱 Fully responsive design
- 🌈 Stunning gradient backgrounds

## Access the Website

Visit: https://thecreepyre.github.io/shiny-rizz/

## How to Use

- **Hover over the light** to see it grow and intensify
- **Click the light** to change colors and create a burst effect
- **Change Color button** - Randomly shift between different color schemes
- **Intensify button** - Create a flash of light

## Technologies Used

- HTML5
- CSS3 (animations, gradients, box-shadows)
- JavaScript (interactivity)

## Customization

You can easily customize:
- Colors in the `changeColor()` function
- Animation speeds in the CSS keyframes
- Light orb size and glow intensity
- Number of twinkling stars

Enjoy the shiny rizz! ✨
